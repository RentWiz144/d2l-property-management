# ChoZen Layout Blueprints

Reusable, mobile-first section stacks. Adapt copy to the specific offer; keep the
structure and the single-action discipline.

## Product / drop landing page
1. Hero — one-line promise + product shot + primary CTA (Shop the drop).
2. Identity line — the "set-apart / chosen" hook that says who this is for.
3. Proof — 3 short testimonials or UGC, faces if possible.
4. Fit & sizing — the "made for every body, largest to smallest" story.
5. Details — fabric, fringes + blue ribband note (where applicable), care.
6. Offer — product/variant grid, price clear, exactly one CTA color.
7. Faith anchor — 1 Peter 2:9 or brand line, tasteful, not preachy.
8. Close — repeat CTA + shipping/returns reassurance (no hype guarantees).

## Email (≤600px)
Preheader → logo → one message → one CTA button → 1 proof → footer w/ unsubscribe.
Never two competing CTAs. Bulletproof button (table cell, not image).

## Link-in-bio
Avatar + one-line who-we-are → 3–5 stacked buttons ranked by priority (Shop,
newest drop, free thing, events) → tiny footer. Highest-intent link on top.

## Bible-app screen (reading view)
Top bar (book/chapter) → verse column (generous line-height, tap-to-expand
precepts/cross-refs) → bottom nav. Reading comfort beats density; large tap
targets; dark mode first-class.

## Lead magnet / opt-in
Headline (the transformation) → 3 bullets of what's inside → email field + one
button → trust line. One field, one button. Deliver instantly.

## Component state checklist (never skip)
Button: default / hover / focus-visible / active / disabled / loading.
Input: default / focus / filled / error (with message) / disabled.
Page: loaded / empty / error / loading skeleton.

## Chart picker (when showing data)
- Trend over time → line. Comparison across items → bar (horizontal if labels are
  long). Part-to-whole → stacked bar or a single donut, never many pies.
- Label directly; kill legends where you can. On-palette. Test light + dark.
