# Z6 · AFTER THE ORDER — Turn buyers into repeat buyers and witnesses

**Owner:** Claude drafts flows → Amoz approves → set once · Wife (UGC reposts) · **Tools:** Klaviyo, Shopify

> Selling out is when people want it most. Keep a way for them to buy, and a reason to come back.

## Post-purchase flow (set once, runs every drop) → copy in [messages.md](messages.md#post-purchase)
| When | Email | Job |
|---|---|---|
| Right after order | "you got it. here's what happens next" | Thank them, **ship window in bold**, a real person reads replies |
| On the thank-you page | Digital add-on ($9–19) | Margin. The "Drop + Study" bundle |
| When delivered | "it's here. how to wear it" | 3 ways to style it, fit tip, care (wash cold, inside out, hang dry), the "Why the Fringes" guide link |
| 1 week after delivery | "tag us wearing it" | UGC + testimony ("Why are you ChoZen?"). Repost every one |
| 2 weeks after delivery | "you're first next time" | Invite to the next drop's early-access list |
| 60 days, no repeat | Winback | One honest note + the next drop date (no discount spiral; cap at 10–15%) |

## Abandoned cart (set once)
| When | Subject | Body |
|---|---|---|
| 30–60 min | you left something | Your size is still in stock → **Finish checkout** |
| 4–8 hours | not sure about the fit? | Fit · fabric · how it wears · size chart → **Finish checkout** |
| 20–24 hours (only if still in stock) | last reminder | Last time we'll mention it → **Get it** |
Text versions only go to people who opted in. Skip #3 if that size sold out. **No flow may send during Shabbat.** *Unknown: whether Klaviyo can block Friday-sundown → Saturday-sundown on its own. Before turning any flow on, check each flow delay's day/time restrictions in Klaviyo and set them to skip Friday evening and Saturday. If it can't be guaranteed, that flow stays off (hard stop).*

## The witness engine
- Every package carries the "Why are you ChoZen?" card.
- Repost every tagged fit. Feature one customer testimony per week (with permission).
- Testimonies feed the next drop's Z1 stories and the PDP.

## Restock & waitlist
Sold-out sizes → Klaviyo back-in-stock signup. The waitlist count is the demand data for the next numbered run.

**Exit gate:** both flows live, every UGC tag reposted, waitlist on for sold-out sizes.
