## Pre-order setup (hero pieces): the safeguards are mandatory
The kit's author lost money to chargebacks from buyers who didn't read the ship time. We pre-order every hero, so we close every gap:

1. **Ship window in bold in 5 places:** product page (above the button), cart, checkout/order note, confirmation email, confirmation text. Example: **"PRE-ORDER · Numbered run · Ships [date range]."**
2. **A real ship date range,** not "soon." Production lead time + 7 days of padding.
3. **A numbered run cap set in inventory**, equal to what you'll actually make. When it's gone, it's gone. Say "numbered run of [N]" only if N is real.
4. **Window length 7–10 days**, closing Sunday–Thursday (the calendar tool checks this).
5. **Sunday update email** to every pre-order buyer, every week until shipped (template in messages.md). Sunday, never on Shabbat.
6. **Delay = same-day notice** with a new date and a one-click cancel/refund option. *(The FTC Mail/Internet Order Rule requires shipping within the stated time, or notifying the buyer and offering a cancel. Verify current requirements on ftc.gov before the first pre-order drop.)*
7. **Card statement descriptor** reads "CHOZEN" so nobody disputes a charge they don't recognize (Shopify Payments → statement descriptor).
8. **Charge timing:** decide charge-now vs. charge-at-ship based on what our Shopify pre-order setup actually supports. **Unknown; verify in Shopify admin before launch.**

Entry tees / supporting pieces: in-stock or POD, regular shipping. Label them clearly so pre-order and in-stock ship times never get confused in one cart. *(If a cart mixes both, the order ships together at the pre-order date; say so on the PDP.)*

## Who gets what (don't blast everyone the same message)
1. **Early-access list:** everything first.
2. **Past buyers:** they trust you. Invite, don't hard-sell.
3. **Engaged, never bought:** show the piece on a body, answer fit.
4. **Started checkout:** the abandoned-cart flow handles them.
5. **Bought this drop:** stop selling. Ask for the post and the testimony instead.

## If something breaks
- **The link breaks:** text the list immediately with the fixed link and say what happened. People forgive a quick, honest fix.
- **Sold out in minutes:** don't kill the momentum. Open a restock waitlist (Klaviyo back-in-stock) and show the sold-out post as proof. Never extend a numbered run quietly.
- **The window is slow:** don't fake urgency. One honest reminder at −24h, then let it close. Small runs are still wins.

**Exit gate:** every row done, the window closed on time, orders counted.
